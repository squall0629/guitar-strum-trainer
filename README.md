# 🎸 吉他扫弦练习助手

实时分析扫弦节奏、音色、强弱，获得专业反馈的桌面练习软件。

## 功能特点

### 核心功能
- 🎤 **实时音频分析** - 低延迟麦克风监听 (<50ms)
- 📊 **多维度评分** - 节奏准确度、音色纯净度、强弱控制
- 💡 **即时反馈** - 每次扫弦获得实时建议
- 📈 **练习记录** - 自动保存历史成绩
- 🎵 **智能节拍器** - 40-200 BPM 可调，强拍高音提示
- 🔊 **节奏型演示** - 5 种节奏型音频演示，快速学习
- 🎚 **灵敏度调节** - 1-100 级可调，适应不同吉他和环境

### 内置节奏型

| 节奏型 | 模式 | 适用风格 |
|--------|------|----------|
| 前八后十六 | ♪ ♫♫ | 流行、民谣 |
| 前十六后八 | ♫♫ ♪ | 流行、摇滚 |
| 民谣常用 | 下 下上 上下上 | 民谣弹唱 |
| 摇滚八分 | 下上下上 下上下上 | 摇滚、朋克 |
| 华尔兹 | 下 上上 下 上上 | 3/4 拍曲目 |

## 评分算法

### 节奏准确度 (50% 权重)
- 对比用户扫弦间隔与目标节奏型
- ±30% 容差范围内得满分
- 超出容差按比例扣分

### 音色纯净度 (30% 权重)
- 分析高频能量分布 (60%-100% 频段)
- 理想值 130 (明亮但不刺耳)
- 偏离理想值扣分

### 强弱控制 (20% 权重)
- 计算振幅稳定性 (方差)
- 方差越小得分越高
- 鼓励均匀有力的扫弦

## 开发日志

- **2026-04-03 v1.8**: 音质重大升级 - 真实吉他采样 + 专业扫弦算法
  - 🎸 使用 FluidR3 GM 钢弦吉他真实采样 (CC0 授权)
  - 🎵 演示音色从合成器升级为真实录音
  - 🔊 模拟真实扫弦效果：6 根弦错开 4-12ms
  - 💡 下扫/上扫不同力度和速度处理
  - ⚡ 自动加载音源，失败时降级为合成音色
  
  **扫弦原则：**
  - **分区扫弦**：低音区 (E3-B3-E4) 重扫，高音区 (G#4-B4-E5) 轻扫
  - **力度层次**：低音下扫 (1.0) > 低音上扫 (0.6) > 高音下扫 (0.3) > 高音上扫 (0.2)
  - **速度对比**：下扫更快 (4-8ms/弦)，上扫更慢 (6-12ms/弦)
  - **方向逻辑**：下扫从低到高，上扫从高到低
  - **16 分音符**：必须用上下扫组合，下扫比上扫重
  - **随机变化**：±10% 力度波动，模拟真人演奏
  - **节奏型原则**：
    - 前八后十六：下 下上 (3 次)
    - 前十六后八：下上 下 (3 次)
    - 民谣常用：下 下上下上 下 (6 次)
    - 摇滚八分：连续上下扫 (8 次)
    - 华尔兹：强弱弱循环 (6 次)
  
  **节拍器优化：**
  - 默认速度从 120 BPM 降至 70 BPM（更适合练习）
  - 强拍高音 (1200Hz)，弱拍低音 (800Hz)
