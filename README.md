# 🎸 吉他扫弦练习助手

实时分析扫弦节奏、音色、强弱，获得专业反馈的桌面练习软件。

## 功能特点

### 核心功能
- 🎤 **实时音频分析** - 低延迟麦克风监听 (<50ms)
- 📊 **多维度评分** - 节奏准确度、音色纯净度、强弱控制
- 💡 **即时反馈** - 每次扫弦获得实时建议
- 📈 **练习记录** - 自动保存历史成绩
- 🎵 **智能节拍器** - 40-200 BPM 可调，强拍高音提示
- 🔊 **节奏型演示** - 5 种节奏型音频演示，快速学习
- 🎚 **灵敏度调节** - 1-100 级可调，适应不同吉他和环境

### 内置节奏型

| 节奏型 | 模式 | 适用风格 |
|--------|------|----------|
| 前八后十六 | ♪ ♫♫ | 流行、民谣 |
| 前十六后八 | ♫♫ ♪ | 流行、摇滚 |
| 民谣常用 | 下 下上 上下上 | 民谣弹唱 |
| 摇滚八分 | 下上下上 下上下上 | 摇滚、朋克 |
| 华尔兹 | 下 上上 下 上上 | 3/4 拍曲目 |

## 技术架构

- **框架**: Electron 28
- **音频处理**: Web Audio API
- **分析算法**: 
  - RMS 音量检测

## 评分算法

### 节奏准确度 (50% 权重)
- 对比用户扫弦间隔与目标节奏型
- ±30% 容差范围内得满分
- 超出容差按比例扣分

### 音色纯净度 (30% 权重)
- 分析高频能量分布 (60%-100% 频段)
- 理想值 130 (明亮但不刺耳)
- 偏离理想值扣分

### 强弱控制 (20% 权重)
- 计算振幅稳定性 (方差)
- 方差越小得分越高
- 鼓励均匀有力的扫弦
